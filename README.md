# DOC 515 Interactives

Static presentations and interactive learning activities for Foundations of Documentary Filmmaking.

- `filmability-test/` — Module 1, Lesson 1
- `documentary-form-presentation/` — Module 1, Lesson 2 slide presentation
- `documentary-form-lab/` — Module 1, Lesson 2 interactive lab
- `sequence-builder/` — shot and sequence practice

Every activity is built with HTML, CSS, vanilla JavaScript, and editable JSON where educational content is data-driven. No activity requires a login, backend, analytics, student-data collection, or numerical scoring.
